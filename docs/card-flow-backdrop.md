# 卡片样式动态流光背景

此功能仅在音乐锁屏的卡片样式开启。设置页只提供一个动态流光开关；旧配置和备份读取原有 `enabled` 状态，忽略过去的预设、强度、速度和模糊字段。默认关闭，完整封面样式不显示流光。

## Apple Music Web 参数

渲染目标来自 [Aadish Verma 的逆向分析](https://www.aadishv.dev/music)和[重建代码](https://github.com/aadishv/html-music/blob/4ef618ea2638a0c435d23f182f7aa10e30757ef6/bundle.ts)：四层专辑封面尺寸分别为视口宽的 125%、80%、50%、25%；第二层起点为 `(0.4W, 0.4H)`，后两层沿半径 `W/4` 的轨道运动，第四层加 `0.05W` 的 X/Y 偏移；旋转速度为 `+0.003/-0.008/-0.006/+0.004 × deltaMs/33.333333`。中心 Twist 的角度为 `-3.25`、半径为 900 逻辑像素并采用平方衰减。模糊采用 Pixi 7.4.3 的 15 点核、每轴 10 轮与 100/10 逻辑像素采样步长，最后将饱和度设为 2.75。动画最多每秒更新 15 帧；暂停音乐仍持续流动。

`CoverCardLayer` 在封面准备线程生成 512×512 的正方形输入图。`AppleMusicFlowEngine` 在宽 256 像素、高度随屏幕比例变化的硬件 `RenderNode` 中合成清晰封面，依次应用 Android `RenderEffect` 扭曲、模糊和饱和度。Android dp 近似对应网页 CSS 像素，采样距离随工作缓冲区比例缩放。此实现追求已公开的网页版参数和运动方式，不宣称与 iOS/macOS 原生效果逐像素一致。旧 Kawarp-AGSL 引擎源码仍保留在仓库中供来源追溯，但此流光路径不再调用；见根目录 `NOTICE`。

## 锁屏合成与回退

整屏流光与展开后的媒体卡、通知卡共用同一硬件场景。卡片根据实际 View 变换映射到根流光坐标，因此拖动和形变时图案保持连续；卡片叠层最高 65% 不透明度。动态层仍位于快捷圆盘、封面、歌词及锁屏根层之下，换曲使用 180 毫秒过渡，初次显示以 220 毫秒渐显。歌词页沿用同一流光并最多压暗 40%；AOD、解锁或组件隐藏后停止更新。视频壁纸保留静态封面底图并随流光透明度让出画面。

硬件绘制失败、封面尚未就绪或关闭开关时，动态层透明，原静态壁纸继续显示。软件画布截图不触发硬件渲染失败。HyperOS 原生玻璃组件可能仍从底层静态壁纸取模糊样本；最终合成及性能需在目标设备上目视确认。
